# Белорецкая узкоколейка

`../buzhd.geojson` — неизменённый файл владельца, полученный 09.11.2026, 53 853 байта. Источник линий: участники OpenStreetMap; ODbL 1.0: https://opendatacommons.org/licenses/odbl/1-0/ . Атрибуция: «Трасса: © участники OpenStreetMap». Публичная копия: `public/region/buzhd/buzhd.geojson`, также под ODbL 1.0.

41 линейный фрагмент: north 18, south 1, tukan 14, peat 8. Шесть исходных точек сохранены в оригинале. Четыре достопримечательности показаны через общий каталог; две точки штампов используют прежние kiosk3/kiosk8 без изменения их данных. Новые станции и соединения между фрагментами не добавлены.

Новые координаты ГР-231 взяты из задания и файла владельца (источник в файле: OSM node 9961390218); прежние координаты narrowGauge2 сохранены в passport-source.json. API OpenStreetMap проверен 09.11.2026: 53.9521799, 58.3385407, совпадение до округления. Ответ сохранён в gr231-coordinate-verification.json. Независимая сверка по Яндекс-панорамам не выполнена; это не геодезическая проверка. Для ТУ7А использовано уточняющее описание из файла: памятник у бывшего места паровоза, а не рядом с его новым расположением.

Паровоз на карте — приблизительная процедурная модель серии ГР, тендер и небольшой вагон. Движение — историческая иллюстрация: дорога разобрана. Одна движущаяся модель в видимом фрагменте north/tukan, от масштаба 14; 85 секунд движения и 95 секунд паузы. Торфяная ветка и разрывы не используются. Анимация не работает при системном уменьшении движения, скрытой карте или вкладке и отключается в слоях. Модель памятника остаётся статичной.
