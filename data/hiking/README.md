# Источники пеших маршрутов и локальных природных сцен

Сырые HTML, OSM XML и PBF не публикуются в Git. Они кэшируются здесь для подготовки данных скриптом `scripts/prepare-hiking-data.py`; исходные URL и SHA-256 указаны в публичных аудитах `public/region/hiking/*/`. Установка GIS-зависимостей: `requirements-gis.txt`.

В репозиторий включены только отчёт исследования источников, метаданные открытого PGC STAC с результатами локальных запросов и небольшая OSM-производная линия BRouter для сравнения расчёта подъёма. BRouter не вызывается браузером опубликованной программы. Публичные туристические GPX Большой уральской тропы не перераспространяются.

Описание метода, источников, поправок координат и ограничений: `docs/HIKING-ROUTES.md`. Начала маршрутов взяты из задания; вершины сопоставлены с OSM. Исходные файлы горнолыжного комплекса не изменены.
