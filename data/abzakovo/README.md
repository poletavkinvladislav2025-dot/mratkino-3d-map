# Сверка Абзаково, 23.10.2026

Публичные исходные ID, теги, узлы и SHA-256 выгрузки сохранены в `public/region/abzakovo/source-audit.json`. Производные данные воспроизводит `scripts/prepare-abzakovo.py` (повторный ограниченный запрос OSM при отсутствии кэша или с `--refresh`). Геометрия OSM распространяется с атрибуцией ODbL-1.0.

Локальные XML, HTML и JPG — исследовательский кэш, исключены из Git. Официальная схема не геопривязана; использована только для сопоставления номеров и типов, не перерисовывается и не распространяется. `source-research.json` фиксирует ссылки и контрольные суммы проверенных копий. Подробные ограничения: `docs/ABZAKOVO.md`.

`prepare-abzakovo-detail.py` сохраняет расчётные просеки, маски леса/препятствий и компактные позиции сосен с реальными высотами Mapterhorn. Четыре PBF лесного покрова и четыре WebP высот — кэш, исключённый из Git; ссылки и SHA-256 находятся в `public/region/abzakovo/forest-instances.json`. Ширина для иллюстрации приблизительная, не официальная граница трассы. Исходные линии в `trails.geojson` сохранены без изменения.
