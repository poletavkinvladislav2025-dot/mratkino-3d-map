# Мраткино — интерактивная 3D-карта

Проект интерактивной карты горнолыжного центра «Мраткино» для Visit Beloretsk.

Цель: создать современную визуализацию рельефа, горнолыжных трасс и подъёмников с адаптацией под мобильные устройства и возможностью последующего встраивания в сайт на Tilda.

Исходную схему трасс необходимо использовать как ориентир; координаты, высоты, трассы и подъёмники требуют проверки до публикации.

Первый этап: рабочий прототип карты.
