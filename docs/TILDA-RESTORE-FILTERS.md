# Восстановление фильтров в T123 · 27.10.2026

Повторное чтение https://visitbeloretsk.ru/map вернуло HTTP 200, 440652 байта. В текущем HTML присутствует старый длинный inline-переключатель с вызовами `show(false)` на старых вкладках. Подключений `tilda-map-block.js` и `tilda-map-switch.js` нет. Поэтому актуальные три фильтра и управление 3D-командами из репозитория на эту страницу не попадают. Это отличается от HTML, проверенного при предыдущей публикации.

Нужна замена **всего содержимого T123 переключателя** (ранее record `rec5086753101`) на [короткую актуальную вставку](snippets/tilda-map-complete.html). Новый тег не следует добавлять после старого inline-скрипта: тот скрывает собственный record. Обычный Яндекс-блок можно оставить; актуальная вставка автоматически изолирует его. Затем опубликовать страницу Тильды и выполнить Ctrl+F5.

В актуальном файле остаются три фильтра: «Места», «Где поставить штамп», «Где купить паспорт». Они работают в выбранном движке. Исправленное оформление T123 входит в тот же файл. Новая карта или иной путь не создаются; повторной публикации GitHub Pages для восстановления подключения не требуется.

Для проверки сохранён текущий HTML и локально заменено только содержимое прежнего T123; остальные блоки, опубликованный 3D-iframe и API Яндекса используются настоящие. Редактор Тильды и сама опубликованная страница агентом не изменялись.

Проверка замены завершена: все три фильтра сохранили режим 3D, масштаб менялся между городскими пунктами и общим планом; затем открыта обычная карта. Ошибок JavaScript не получено. Код приложения не изменялся, поэтому повторные сборка и дорогие браузерные матрицы не запускались.
