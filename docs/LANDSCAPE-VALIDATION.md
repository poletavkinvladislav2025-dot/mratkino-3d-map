## Измерения и границы проверки

[Измерение одной сцены](landscape-runtime-measurements.json): 9852 дерева, 23 геометрии/вызова отрисовки моделей, JS heap всей страницы около 97 МБ. Это не универсальный замер FPS и не общий предел памяти браузера. Пороговые бюджеты общего слоя: 12000/3600 деревьев, 9/4 выбранных ячеек, кеш 18/8, целевой бюджет собственного слоя 24/10 МБ для компьютера/телефона. Подробнее: [LANDSCAPE.md](LANDSCAPE.md).

Не проверены физические Android/iOS, Safari, реальный опубликованный T123, полевая точность геометрии и текущая работа курортов. Три фотографии из текста задания не приложены; модель выполнена по описанию, photo и photoCredit пусты. Четыре места без надёжной привязки не нанесены; перечень и конфликты цветов/числа трасс: [WINTER-SOURCES.md](WINTER-SOURCES.md).

Общий генератор работает по покрытию семантических данных, но проверка одной дополнительной территории не подтверждает точность всей России. При отсутствии подтверждённого леса или ошибке источника новый лес не придумывается. Для национального каталога потребуется индекс точек; данные всей страны не скачивались.
