# Проверка маршрутов и локальных сцен — 23 октября 2026

Описание данных и ограничений: [HIKING-ROUTES.md](HIKING-ROUTES.md).

## Успешные проверки

- **18 Node.js:** пять вариантов только по существующим рёбрам OSM, порядок вершин, точное повторение обратного пути, точка Второй Малиновой, границы загрузки и лимиты природы; прежняя география и LOD Мраткино; 360/144 персонажа, реальная ширина асимметричного полигона, отверстия, правильная сторона наклона, расстояние не менее 2,8 м в симуляции с 360 фигурами и исключение закрытого полигона С1.
- **8 Python:** прежний GIS/DEM/лес и сохранение отложенных модулей; новая проверка всех 68 834 кандидатов деревьев двух гор: не ближе 4,98 м к маршрутам с учётом округления координат, только в коридорах 250 м / зонах вершин 500–700 м, за пределами нанесённых открытых скал, осыпей и полян.
- **7 браузерных сценариев на производственной сборке:** все пять переключателей и маркеры вершин; смена направления с обменом старта/финиша; возврат из плоского вида к 3D при выборе маршрута; одна карта Малиновая → Ялангас → Мраткино; отсутствие тяжёлых сцен до нажатия кнопки; появление деревьев и скальных поверхностей, лимиты ячеек и выгрузка; iframe 390 px с сенсорным контекстом без горизонтального переполнения; повторная загрузка после отказа GeoJSON и сохранение маршрута при отказе модуля природы; прежние отказы данных/сцены Мраткино; 360/120 и 144/48 фигур/сноубордистов, видимая геометрия, изменение матриц при анимации, пауза и закрытая С1.
- `npm run build` и `git diff --check`: успешно. Исходные `public/live/` не изменены.

Команды:

```sh
npm run test:unit
python -m unittest discover -s tests -p 'test_*.py'
npm run build
TEST_PRODUCTION=1 npx playwright test tests/hiking.spec.js tests/hiking-recovery.spec.js tests/rider-crowd.spec.js tests/recovery.spec.js
```

Заключительная браузерная серия заняла 5,2 минуты в Chromium/SwiftShader. Это время тестирования с программным GPU, не время загрузки для посетителя. Реальные тайлы получены через тестовый relay с проверкой TLS upstream; он не включён в опубликованную карту. Физический смартфон и гарантированный FPS не проверялись. Проверенные состояния не выявили необработанных ошибок JavaScript; отказы HTTP 503 в сценариях восстановления созданы намеренно.

## Ограничения результата

Связность OSM не подтверждает безопасность или проходимость троп. Подходы от стартов к ближайшей линии и последние 1,7–16,5 м к вершинам не дорисованы. Положения вершин, отличающиеся от задания, показаны в отчёте данных. Высокоточная лицензированная модель местных скал не установлена; исходный DEM не заменён вымышленной геометрией. Деревья процедурные, расположение отдельных реальных деревьев не обследовано.
