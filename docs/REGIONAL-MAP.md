# Тестовая единая карта Visit Beloretsk

Новая версия публикуется отдельно:

https://poletavkinvladislav2025-dot.github.io/mratkino-3d-map/preview/region/?place=all

Корневой адрес, который использовался для Мраткино, сохраняет сборку `af1a594`. Действующий сайт Tilda не изменяется. Контрольная точка исходного проекта: `checkpoint/before-regional-map-2026-10-22`.

## Что реализовано

Один экземпляр MapLibre: общий рельеф, лесная поверхность, реки, улицы, 22 природные/горнолыжные локации и Белорецк. Переключение начальных видов меняет камеру и слои, не пересоздаёт карту и не ограничивает перемещение.

- `src/region/places.json` — координаты, тип объекта, источник сверки и ограничения доступа.
- `src/region/presets.js` — камеры и зоны около 10 км. Активны до четырёх ближайших зон при масштабе от 11,5; вне этих зон подробная сцена не запускается.
- `src/region/style.js` — общий стиль без городских POI, подписей улиц, названий зданий и объёмных зданий.
- `src/region/controller.js` — выбор места, подписи с устранением пересечений, локальная загрузка Мраткино, импорт треков.
- `src/region/routes.js` — GeoJSON/GPX, начало/конец, остановки, длина, набор высоты только при наличии высот в файле, указанное автором время. Разрывы сегментов не соединяются. Файл остаётся в браузере.
- `src/resort-scene.js` — инстансинг хвойных моделей, кресла и одиночные тарелки, лыжники/сноубордисты. Движение условное. С1 закрыта и исключена из спусков.

Обзор района загружает только тайлы видимой области. Семь локальных GeoJSON Мраткино подгружаются при приближении к комплексу; бинарные позиции 80 058 деревьев и Three.js — после кнопки «Оживить карту». При уходе от курорта объёмная сцена освобождает ресурсы. Вне Мраткино используются лесные полигоны, без отдельных 3D-деревьев. Перемещения и загрузка тайлов кэшируются движком и браузером; в памяти остаётся один набор исходных данных курорта.

Колесо на компьютере работает без Ctrl, относительно курсора. На устройствах с сенсорным основным указателем сохранены два пальца для карты и один для прокрутки страницы. Обычная прокрутка вне карты сохраняется.

## Координаты и достоверность

Сверка: 22 октября 2026 года, OpenStreetMap Overpass/API 0.6. Отчёт: `public/region/coordinate-audit.json`. Это сопоставление открытых объектов, а не геодезическая съёмка. Вершины, смотровые точки, ориентиры хребтов и приблизительные точки комплексов различаются в данных и карточках.

Особые случаи:

- Малый Ямантау сопоставлен с ближайшей к заданию вершиной 974 м, а не с одноимённой вершиной 1513 м возле Большого Ямантау.
- Мраткино: исходная точка комплекса и точка вершины 795,1 м сохранены раздельно.
- Первая Малиновая привязана к вершине OSM «Малиновая (1)», 914,7 м; Третья — «Малиновая (3)», 1152 м.
- Айгир привязан к видовой точке хребта Караташ; Инзерские Зубчатки — к ориентиру массива, не к вымышленной единственной вершине.
- Хребет Крака: оставлен ориентир из задания, не выдан за конкретную вершину. Абзаково: приблизительная точка комплекса, без детализации его трасс.
- Белорецк: узел города OSM `node/253261493`, 58.4099549, 53.9680705.
- Для Ямантау и Малого Ямантау показано ограничение заповедника, для Иремеля — необходимость уточнения правил парка. Разрешения на посещение карта не предоставляет.

Спорная дополнительная линия справа от Ю4 — `way/933862767`, `piste:difficulty=freeride`, `piste:grooming=backcountry`. Она исключена фильтром слоя трасс. Исходный GeoJSON сохранён; семь именованных трасс и Ю4 не удалены. Ю3 сохраняет исходное противоречие ref=Ю2 в сведениях об источниках.

## Маршруты

Проверенных туристических треков в комплекте пока нет. На сайте Большой уральской тропы проверена доступность источника; открытая лицензия на перераспространение его треков не установлена. Ссылки, упрощённые схемы и название тропы не выдаются за подтверждённый маршрут. Есть ссылка на первоисточник и локальный импорт GPX/GeoJSON. Пользовательский трек показывается с пометкой «не проверен».

Необязательный слой троп OSM показывает реальные линии исходной векторной карты, а не специально рекомендованные туристические маршруты. Условия доступа и актуальное состояние не подтверждены. Набор высоты из импортированного файла считается без фильтрации GPS-шума и помечается как приблизительный; время без исходных сведений не оценивается.

- OpenFreeMap — бесплатный публичный сервис, без ключа и платного API. Используются обычные запросы тайлов видимой области, без массового скачивания района. Условия: https://openfreemap.org/tos/ (проверены 22.10.2026).
- Mapterhorn — открытые источники рельефа, Terrarium WebP, тайл 512. https://mapterhorn.com/attribution . Преувеличение высот 1.
- Локальные исходные Copernicus DEM GLO-30 и сведения об их лицензии сохранены в прежней сцене; региональная версия не скачивает весь DEM заранее.

Тайлы открытых сервисов требуют интернета. Зимняя окраска — оформление; актуальные условия снега и работу курорта карта не показывает.

## Публикация и старые вкладки

`.github/workflows/pages.yml` запускается вручную из `main`; параметр `preview_ref` указывает ветку тестовой версии. Это использует существующее правило GitHub Pages, разрешающее публикацию только из `main`, без изменения защиты окружения. Workflow собирает новую версию в `/preview/region/` и отдельно собирает неизменённый `af1a594` для корня. Продвижения новой версии в корень автоматически нет.

`base: './'` сохраняет работу под вложенным адресом GitHub Pages. Относительные пути данных вычисляются от корня конкретной сборки, worker поставляется локально. Скрипт `retain-pages-assets.py` сохраняет хешированные JS/MJS/CSS двух предыдущих тестовых сборок. Благодаря этому вкладка, открытая перед публикацией, может позднее загрузить свой старый модуль Three.js. В `build-info.json` сохраняются ссылки и SHA-256 файлов.

При сетевой ошибке модуля базовая карта остаётся доступной, если она уже загружена. Отдельная кнопка предлагает загрузить свежую версию с сохранением `?place=…`; автоматического бесконечного перезапуска нет. Сохранение двух прошлых сборок не заменяет обработку длительного отсутствия сети.

## Начальные виды и встраивание

Доступны `all`, `beloretsk` и каждый `id` из `places.json`, включая `mratkino`, `aygir`, `yalangas`, `malinovaya`, `malinovaya-3`, `iremel`, `abzakovo`.

Минимальный код для **тестовой** страницы Tilda T123:

```html
<iframe
  src="https://poletavkinvladislav2025-dot.github.io/mratkino-3d-map/preview/region/?place=mratkino"
  title="3D-карта Мраткино — Visit Beloretsk"
  style="width:100%;height:1100px;border:0;display:block"
  loading="lazy" allow="fullscreen" allowfullscreen>
</iframe>
```

Для другой страницы достаточно заменить `place=mratkino` на `place=beloretsk`, `place=all` или идентификатор горы. Отдельные копии программы не нужны. Высоту можно подобрать под блок Tilda; панель на телефоне раскрывается кнопкой, а полноэкранный режим относится к самой карте.

При просмотре публичного HTML главной страницы Visit Beloretsk iframe карты не обнаружен. Это не позволяет установить настройки блока на другой странице или в редакторе Tilda; доступ к редактору не использовался. Существующий подготовленный код `public/tilda-embed.html` указывает на прежний корневой адрес GitHub Pages и не изменён.

## Проверка

`npm run test:unit`, `npm run build`, браузерные проверки Playwright. В облачном Chromium сертификат внешнего тайлового сервера не распознаётся хранилищем среды, поэтому тестовый relay `tile-test-proxy.py` получает реальные тайлы через Python requests с проверкой TLS. Он не входит в опубликованную программу и не подменяет географию синтетическими данными. Итоговые измерения загрузки и перечень проверок — `REGIONAL-VALIDATION.md`.
