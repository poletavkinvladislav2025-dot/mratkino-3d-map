# Источники и неподтверждённые сведения

Проверено 23.10.2026. Координаты: OSM/Nominatim и опорная точка этнопарка от владельца. Полученные страницы и результаты сопоставления: `data/landscape/sources.json`, `geocoding.json`, дополнительные `*-geocoding.json`; сырые HTML/XML сохранены локально. Ограниченные OSM map API выгрузки выполнены однократно; браузер их не запрашивает. Два Overpass endpoint вернули 406/429, поэтому применён ограниченный OSM map API.
