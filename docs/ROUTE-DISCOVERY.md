# Названия по нажатию и детализация ГЛЦ — 24.10.2026

Обновляется одна общая карта: https://poletavkinvladislav2025-dot.github.io/mratkino-3d-map/preview/unified/?place=all. Вставка Tilda и адрес не меняются.

Нижняя полоса с цветами, категориями и названиями убрана. Обе полные линии GPX сохраняют прежние красный/жёлтый цвета, толщину, координаты и загрузку в начальном стиле. Нажатие в пределах 7 экранных пикселей от линии открывает небольшое окно с названием; если в точке видны оба трека, показаны оба названия. Название не появляется от наведения. Окно закрывается при перемещении карты, следующем нажатии, крестиком или отключении соответствующего маршрута. Обычное обновление неподвижной сцены его не закрывает. На пересечениях горнолыжные трассы, подъёмники и существующие локальные пешие маршруты сохраняют приоритет своих карточек. Названия источников в обязательной атрибуции сохранены.

Существующая автоматическая загрузка Мраткино/Абзаково по области просмотра сохранена. Линии трасс появляются при приближении; номера/названия непосредственно на склонах показываются с zoom 13.4. Для обоих курортов теперь одинаково соблюдается флажок «Подписи». Нажатие на локальную трассу открывает существующую карточку. Для этого не нужно выбирать ГЛЦ в поиске или включать «Оживить карту».

Проверки: `npm run test:unit`, `npm run build`; фокусные браузерные сценарии `tests/long-distance.spec.js` и `tests/route-discovery.spec.js`. Используются реальные GPX и реальные тайлы через существующий relay. Геометрия и полный охват маршрутов проверяются прежними тестами. Новые сценарии проверяют реальные нажатия по красной/жёлтой линии на desktop/mobile, отсутствие легенды, сохранение popup при sync и закрытие при отключении, автоматическое появление трасс и подписей обоих ГЛЦ без выбора места, отключение подписей и карточку по нажатию. Прямая живая страница Tilda не редактировалась.
