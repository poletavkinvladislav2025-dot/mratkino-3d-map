# Исправление установленной страницы Тильды · 27.10.2026

На этот раз https://visitbeloretsk.ru/map удалось прочитать: HTTP 200, 342676 байт. В опубликованном HTML одновременно находятся старый `.vb-t1` Яндекс-блок (record `rec4164654901`, включая его вкладки и скрипт) и новая вставка `tilda-map-block.js?v=20261027-filters`. Прежний полный блок при наличии `.vb-t1` прекращал запуск и показывал предупреждение. Тесты установки в пустой T123 этого сочетания не покрывали. Предложение вручную удалить два блока оказалось хрупким способом обновления.

Теперь тот же полный блок сам обновляет такое окружение. Старые секции/переключатели скрываются вместе с их record, если в нём нет текущей вставки; при совместном record скрывается только старый узел. Старый DOM сохраняется для старых замыканий. Новые карта, вкладки, стили и адаптер создаются внутри одного ShadowRoot. Поэтому старые обработчики/поиск по ID/стили не управляют новым блоком. Повторный запуск вставки идемпотентен.

Адаптер и события Яндекса у нового блока принадлежат его ShadowRoot; глобальный `VisitBeloretskYandex` старой карты не перезаписывается. Общий переключатель принимает необязательную `vbScope` на создающем script и работает с ней. Сам script остаётся в обычном DOM: `document.currentScript` для script внутри ShadowRoot равен null. Для обычной несоставной установки переключателя прежняя область document/window сохранена.

API Яндекса добавляет CSS в head документа. `yandex-styles.js` переносит в ShadowRoot только его правила `.ymaps-<version>` и стили с хостов Яндекса, включая правила, добавленные через CSSOM. Глобальные стили Тильды не копируются. Данные мест и существующий 3D-адрес не менялись; исправлен только слой подключения.

## Что сделать владельцу

Уже опубликованная вставка на странице подходит. После обновления GitHub Pages достаточно заново загрузить https://visitbeloretsk.ru/map с Ctrl+F5. Редактировать Тильду, менять адрес карты или вставлять очередной промпт не требуется. Если установлена именно указанная вставка, она автоматически получает новый изолированный блок. Непосредственно HTML/настройки страницы Тильды агент не изменял.
