# Актуальный переключатель Tilda

[Полная инструкция и код замены T123](UNIFIED-CONTROLS.md).

Исправлено прежнее поведение: фильтры и #map-stamps больше не вызывают show(false) и не переключают движок. Новый вариант использует явный embed=1 и команду setFilters. Старый общий обработчик вкладок не должен оставаться на странице: замените прежний T123 целиком и опубликуйте заново.

[Полный HTML переключателя](snippets/tilda-map-switch.html) · [небольшой адаптер внутри существующего скрипта Яндекса](snippets/yandex-adapter.js).

Без установки адаптера на стороне Яндекса доступны его прежние вкладки, но не полная передача выбранного объекта и фильтра продажи паспорта. Живая Tilda не проверена: при чтении опубликованной страницы получен HTTP 403. Демонстрационный адаптер в тестовом родителе не является API Яндекса.
