# Проверка тестовой региональной карты — 22 октября 2026

Опубликованная программа: https://poletavkinvladislav2025-dot.github.io/mratkino-3d-map/preview/region/?place=all

Сборка программы: `82d10d2`. Публикация GitHub Actions: https://github.com/poletavkinvladislav2025-dot/mratkino-3d-map/actions/runs/39828365307 . Корневая страница прежней карты и её основной скрипт сохранили SHA-256, записанные до изменения workflow. Новая программа размещена только под `/preview/region/`; блоки Tilda не изменялись.

## Выполненные проверки

- **10 проверок Node.js:** 22 разных объекта и все presets, верхняя камера города, зоны около 10 км, реальные исходные данные, только спорная линия фрирайда скрыта, высоты/длина импортированных треков, разрывы сегментов, лес и LOD, одиночные тарелки, компактная инфраструктура с сохранением геометрии и ID исходника.
- **7 проверок Python:** географические преобразования, реальные высоты Terrarium, OSM и маски леса, сохранение старого отложенного JS-модуля при обновлении сборки и отклонение посторонних путей файлов.
- **2 браузерные проверки камеры и сцены:** одна карта для склонов, прерывание перелёта жестом, поворот/наклон/масштаб, 2D/3D; реальные линии подъёмников, хвойные модели, 24 декоративных персонажа на шести трассах, закрытая С1, пауза/возобновление, слои, освобождение сцены и повторное подключение компонента.
- **5 заключительных браузерных проверок:** обзор района без загрузки модулей и данных курорта; переходы Белорецк → Ялангас с сохранением одного экземпляра карты; реальный рельеф и улицы без городских подписей; колесо без Ctrl около курсора; локальный GPX; мобильная ширина и кооперативные жесты; отсутствующий модуль сцены и отсутствующие локальные данные не ломают общую карту и переход к городу.
- **Отдельная проверка iframe:** вложенный путь `/preview/region/`, агрессивные стили родительской страницы, полноэкранный режим и ширина 390 px. Ошибок JavaScript не обнаружено.
- **Отдельная проверка сборки и загрузки:** последовательные переходы района, города, Ялангаса и Мраткино; загрузка сцены по кнопке; после ухода с курорта сцена освобождена. Ошибок JavaScript не обнаружено.
- **Проверка GitHub Pages:** опубликованные HTML и текущие файлы JS/MJS/CSS побайтно совпадают с локальной проверенной сборкой; корректные типы содержимого; сохранённые модули предыдущей тестовой сборки доступны и проверены по SHA-256. Блокирующих iframe заголовков на опубликованной странице не обнаружено.

Команды заключительных проверок:

```sh
npm run test:unit
python -m unittest discover -s tests -p 'test_*.py'
npm run build
TEST_PRODUCTION=1 npx playwright test tests/region.spec.js tests/recovery.spec.js
TEST_PRODUCTION=1 npx playwright test tests/map.spec.js tests/resort-scene.spec.js --grep 'one map changes|3D trees'
MAP_TEST_URL=http://127.0.0.1:4181/preview/region/ node scripts/check-region-production.mjs
MAP_TEST_URL=http://127.0.0.1:4181/preview/region/ node scripts/check-region-iframe.mjs
```

Для браузерных проверок использован системный Chromium с программным SwiftShader. Проверка камеры/сцены заняла около 7 минут: это продолжительность сценариев автоматизации в облачной среде, не время открытия карты для посетителя. На физическом смартфоне производительность GPU в этой среде не измерялась. Объёмная сцена включается отдельно; число моделей и частота анимации ограничиваются, скрытая сцена не анимируется.

Тайлы в облачном Chromium получены через тестовый relay с проверкой TLS upstream-серверов; реальные данные не заменялись тестовым рельефом. Relay не включён в опубликованную программу. В отдельном тесте импортирован явно обозначенный искусственный GPX-файл для проверки парсера; в опубликованной карте такого туристического маршрута нет.

## Объём полученных данных

Измерение: 1440×1080 px, одна карта, последовательные переходы. В таблице **размер тел ответов после HTTP-декомпрессии**, не сжатый сетевой трафик. Перехват запросов в тесте отключает HTTP-кэш Chromium; повторные запросы одинакового тайла могут учитываться повторно. Это не оценка скорости сети пользователя. Данные приложены в `region-loading-measurements.json`.

| Действие | Дополнительно получено | Запросов |
|---|---:|---:|
| Холодный обзор района | 6,09 МБ | 32 |
| Переход к Белорецку | 1,24 МБ | 20 |
| Переход к Ялангасу | 2,45 МБ | 43 |
| Переход к Мраткино | 2,20 МБ | 36 |
| Включение объёмной сцены | 1,14 МБ | 3 |

При первом обзоре района не загружались Three.js, бинарные позиции деревьев или локальные слои Мраткино. Большую часть объёма составляют отображаемые DEM-тайлы и базовый движок с worker. Включение сцены загружает около 504 КБ JS и 640 КБ бинарных позиций. JavaScript дополнительно сжимается сервером при обычной загрузке.

Отдельный файл инфраструктуры содержит 51 исходный объект курорта и занимает **34 571 байт** вместо 1 513 600 байт полной исходной выгрузки из 1793 объектов. Геометрия и ID выбранных объектов не изменены; городской массив не передаётся для подробной сцены. При загрузке всего района максимальная детализация всех локаций не запрашивается.

## Что ещё требует исходных сведений

Хребет Крака и точка комплекса Абзаково сохранены как ориентиры из задания. В остальных случаях использованы совпавшие объекты OSM — это не геодезическая проверка. Работа курорта и открытие трасс в реальном времени не подтверждаются. Проверенные туристические треки ещё не добавлены; тропы OSM и импортированные файлы явно отделены от подтверждённых маршрутов. Для заповедных территорий показаны ограничения доступа.

Дальнейшая оценка владельцем нужна для географии и художественной детализации; действующий сайт Tilda до такой оценки остаётся без изменений.
