# Белорецкая узкоколейка на единой карте

Постоянный адрес: `preview/unified/?place=buzhd`. Это слой существующей карты, отдельная карта и новые страницы сайта не создаются. В меню «Слои» — БУЖД, кнопка показа целиком и отдельный переключатель исторической анимации поездов.

Оригинал владельца: `data/buzhd.geojson`, 53 853 байта, SHA-256 `abe26fa3b94689eb5be3134cde1642a3771b38d87b3ecbad59a92cf2add913c7`. Публичная копия `region/buzhd/buzhd.geojson` идентична оригиналу, ODbL 1.0; ссылка на лицензию и источник в `data/buzhd/README.md`. Папка `dist/data` исключается прежней конфигурацией Vite, поэтому опубликованный ресурс находится в `region/buzhd`.

41 линейный фрагмент и 6 исходных точек сохранены без изменения геометрии. Границы для fitBounds рассчитаны только по линиям, не по памятникам. Нет соединений разрывов или новых станций. Линии MapLibre накладываются на активный 3D-рельеф: north/south тёмно-зелёные, tukan зелёная, peat латунный пунктир. Структуры мост/выемка — 6 px; пунктир остаётся 6/8 px при разной ширине. Надпись появляется с zoom 13; исходная атрибуция OSM доступна в контроле источников. Карточки содержат даты исходного участка, историю дороги и примечания для peat/north.

Четыре памятные точки используют общий каталог: gr231 — дополнительный ID существующего narrowGauge2, tu7/cut/arsha — новые места. narrowGauge1 переименован без изменения типа и исходных координат. У narrowGauge2 новые координаты владельца, подтверждённые API OSM node 9961390218; прежние координаты сохранены в passport-source.json. Сверка по Яндекс-панорамам не выполнена. Ссылки обоих прежних ID ведут на `/uzkokoleyka` в обеих картах через общий каталог; kiosk3/kiosk8 и их штампы не менялись. ТУ7А описан у бывшего места ГР-231 согласно GeoJSON, а не у перенесённого памятника.

Паровоз — приблизительная процедурная модель ГР: котёл, труба, кабина, четыре ведущие оси, тендер и небольшой вагон. Статичная модель стоит у памятника, движущаяся появляется при приближении к полотну (zoom >=14) автоматически. Одна модель на видимом фрагменте north/tukan; 85 секунд движения и 95 секунд паузы, без переходов через разрывы и без торфяной ветки. Это историческая иллюстрация разобранной дороги. Отключается в слоях; движение приостанавливается при управлении камерой, невидимой карте/вкладке и системном уменьшении движения. Геометрия без текстур, Three.js загружается по необходимости. Модель следует высоте DEM, при отсутствии высоты скрывается.

Исходные 214 ID туристических маршрутов и их геометрия не менялись. Новые ID относятся к историческому слою и памятным точкам, не к пешим маршрутам.

После последней правки закрытия popup мобильная проверка повторена успешно. SHA-256 исходного файла, публичной копии и файла в dist совпадают.
