# Близкий ракурс при выборе Родео — 26.10.2026

У Родео раньше использовался общий пресет небольших локаций (zoom 12.6), из-за чего выбор места показывал дальний общий план. Для Родео теперь задан собственный предварительный центр на фристайл-склоне, наклон 55° и поворот −125°. После выбора места рассчитывается близкий ракурс по полосе фристайл-парка с учётом открытой карточки справа или снизу. Композиционная рамка составляет 85% осевого bbox, чтобы пустые углы повёрнутой рамки не отдаляли сам склон. Геометрия парка и координаты места не меняются.

Новый ракурс применяется при выборе через поиск, подпись/маркер, список и команду открытия места; тот же метод использует «Рассмотреть фристайл-парк». Режим `navigate:false` сохраняет прежний смысл. Явная камера из ссылки по-прежнему имеет приоритет при загрузке. Карточка остаётся открытой, движение не включается автоматически, камера и карта не создаются заново. Общий стартовый обзор Белорецк — Абзаково не меняется.

Проверки: `npm run test:unit` (15 проверок), production build, `tests/rodeo-view.spec.js` — реальный выбор через поиск на desktop/mobile, наклон/поворот, видимость всей полосы вне карточки, крупность, повторный выбор без дрейфа, наличие 96/48 катающихся и один экземпляр карты. Снимки — `renders/rodeo-default-desktop.png`, `renders/rodeo-default-mobile.png`. Используется прежний tile relay с настоящими геоданными.

Публикация выполняется по тому же адресу `/preview/unified/?place=all` через `unified.yml`; менять вставку Tilda не требуется.
