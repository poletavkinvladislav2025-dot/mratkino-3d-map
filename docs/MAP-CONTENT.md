# Короткие карточки и местный начальный обзор — 24.10.2026

Единая опубликованная карта сохраняет адрес `/preview/unified/?place=all`. Код вставки Tilda менять не нужно.

`src/region/map-content.json` содержит отдельный слой редакционных описаний: 51 место, обзор Белорецка, две большие тропы и пять локальных пеших маршрутов. Описания применяются после объединения исходных каталогов и паспорта: координаты, исходные записи, фотографии, связи штампов, ID, геометрия и исходная классификация остаются в прежних файлах. Редакторский слой меняет только текст. Правила посещения заповедных территорий и условия штампов сохранены.

Названия и содержание двух длинных троп проверены по доступным 24.10.2026 первичным страницам:
- https://www.greaturaltrail.ru/ — HTTP 200. Официальное название «Большая Уральская тропа»; проект объединяет короткие маршруты вдоль Урала, основной трек проходит от Пермского края до Оренбуржья. Новый текст — краткий пересказ, не копия статьи. Прежняя недоступность `/map` не относится к доступной главной странице.
- https://suraltrail.ru/ — HTTP 200. «Южноуральская тропа», направление Банное — Абзаково — Белорецк — Инзерские Зубчатки — горные парки — Тургояк. Длина показанного пользовательского GPX остаётся 489.327 км; рекламные длины основной ветки и всей сети не подменяют длину файла.

Названия и географические ориентиры мест опираются на существующие реестры проекта и OSM. В карточках не добавлены новые обещания доступности, времени прохождения, услуг или режима работы. Недоступные страницы Википедии не используются как новые проверенные источники. Для лыжных участков использованы сохранённые теги `piste:type=nordic`, `piste:grooming=classic`, `surface=asphalt` и `roller_ski`. Связь лыжных участков Учалов с биатлоном не утверждается. https://biathlonufa.ru/trassy/ подтверждает биатлонный комплекс и схемы зимних кругов 2–4 км. Перечень прежних спортивных источников — `WINTER-SOURCES.md`.

Название YT_v2-8 заменено в интерфейсе на «Южноуральская тропа». Исходные GPX и GeoJSON сохранены без изменений; отображаемые названия, описания и ссылки наложены в `LongDistanceController`. По нажатию на тонкую линию открываются краткий текст и ссылка «Сайт тропы» в новой вкладке. В нижней части карты легенда по-прежнему отсутствует.

Обычные карточки не содержат редакторских фраз «принадлежность уточняется», «названия кругов требуют сверки», повторов «Маршрут OSM» и подобных заглушек. В спортивных списках разделены спуски, беговые лыжи, подъёмники, тюбинг и тренировочные участки. Существующие названия и номера сохранены; у безымянных линий используются назначения и порядковые метки «участок», не выдуманные официальные названия. Выбранный участок расположен перед сгруппированным списком. Снят дополнительный внутренний скролл списка. Источники доступны отдельным раскрывающимся блоком.

Начальный охват задан явно: `[58.25,53.75] — [58.72,54.07]`, Белорецк, Мраткино и Абзаково. Он не расширяется при добавлении далёких курортов и не зависит от полных GPX. «Домой» возвращает туда же, включая мобильный интерфейс. «Целиком» продолжает показывать всю длинную тропу; перемещение по остальной карте не ограничено. Явная камера из ссылки сохраняет прежний приоритет.

Проверки: `npm run test:unit`, `npm run build`; фокусные production Chromium-сценарии `map-content.spec.js`, `route-discovery.spec.js`, `long-distance.spec.js`, прежние проверки галереи и очереди команд реального iframe из `unified.spec.js`. Используются настоящие GPX и тайлы через существующий relay. Текстовый каталог для просмотра — `PLACE-COPY.md`.
